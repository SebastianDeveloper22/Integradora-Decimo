1 Introducción al Sistema

SIGAB (Sistema de Gestión y Almacenaje de Bienes) es una plataforma web diseñada para administrar el almacén automatizado de DSI. Permite a los operadores de planta solicitar componentes directamente desde su terminal, y al personal de almacén gestionar el inventario y monitorear la actividad del turno.

ℹ️
El sistema se comunica en tiempo real con el robot automatizado de almacén (ESP32) para ejecutar las extracciones de manera física. No es necesario ningún conocimiento técnico para operar el sistema.

Componentes del sistema

Terminal de Operador

Accedida desde cualquier equipo de la red local. Permite solicitar componentes y enviar alertas de emergencia.

Servidor / Almacén

Terminal principal en localhost. Recibe alertas, genera cortes de turno y tiene acceso al panel de administración.

ESP32 + SKR (Robot)

El ESP32 recibe las coordenadas del sistema web, las retransmite a la SKR para el movimiento de los motores y activa la pinza que recoge físicamente el BIN una vez el robot está posicionado.

Base de Datos (Strapi)

Sistema backend que almacena inventario, usuarios, órdenes y registros de actividad.

2 Subsistema SKR — Control de Motores

La SKR es la placa controladora de motores paso a paso (stepper drivers) que gobierna el movimiento físico del robot de almacén. Es el núcleo de actuación del sistema: sin ella, las órdenes generadas en la interfaz web no se traducirían en movimiento real.

⚙️
La SKR opera de forma transparente al usuario. Usted no interactúa directamente con ella; el sistema SIGAB y el módulo ESP32 se encargan de comunicarle las instrucciones de movimiento automáticamente al confirmar una extracción.

Rol en el sistema

Dentro de la arquitectura de SIGAB, la SKR ocupa la capa de control de hardware. Su función es recibir coordenadas de destino y traducirlas en pulsos precisos para los motores paso a paso que desplazan el mecanismo de extracción hasta el BIN solicitado.

Lo que recibe

Instrucciones de posición en los ejes X y Z enviadas por el ESP32, expresadas como coordenadas numéricas mapeadas a los BINs del almacén.

Lo que ejecuta

Genera los pulsos de paso y dirección para cada motor, moviendo el cabezal del robot a la posición exacta del componente solicitado con precisión milimétrica.

Flujo de comunicación

Cuando un operador confirma una extracción, la cadena de comunicación es la siguiente:

🖥️ SIGAB (Interfaz Web)
Genera lista de coordenadas {x, z} por BIN
↓
📡 ESP32
Recibe el JSON de coordenadas vía HTTP POST, lo retransmite a la SKR y activa la pinza al llegar al BIN
↓
⚡ SKR (Controladora)
Interpreta las coordenadas y controla los drivers de los steppers
↓
🦾 Motores paso a paso
Se desplazan a la posición exacta del BIN (ejes X y Z)
↓
🤏 Pinza (ESP32)
El ESP32 activa la pinza para recoger el BIN una vez el robot está posicionado

Ejes de movimiento (X / Z)

El robot de almacén opera en dos ejes, cada uno controlado por su respectivo motor paso a paso a través de la SKR:

EjeDirecciónFunción
Eje X Horizontal Desplazamiento lateral entre columnas de BINs (izquierda / derecha)
Eje Z Vertical Desplazamiento en altura entre filas de BINs (arriba / abajo)

Cada código BIN registrado en la base de datos tiene asociadas sus coordenadas X y Z exactas. Al confirmar un pedido, el sistema consulta esas coordenadas y las envía a la SKR a través del ESP32, que posiciona el mecanismo y ejecuta la extracción.

⚠️
Si la SKR o el ESP32 no responden al momento de confirmar un pedido, el sistema mostrará un mensaje de "Fallo de Comunicación". En ese caso, utilice el botón 🚨 Solicitar Asistencia Técnica para notificar al encargado de almacén.

Credenciales de acceso

Su ID de Empleado y contraseña son asignados por el administrador del sistema. Si no los tiene, contacte al encargado de almacén.

  1. Abra el navegador web en la terminal asignada.
  2. Ingrese su ID de empleado en el primer campo.
  3. Ingrese su contraseña en el segundo campo.
  4. Haga clic en el botón INGRESAR.
  5. Espere mientras el sistema verifica sus credenciales.
✅
Una vez autenticado correctamente, el sistema recordará su sesión aunque cierre o recargue la página, hasta que haga clic en Cerrar Sesión.

5 Lista de Extracción

La Lista de Extracción (identificada con el ícono 🛒) funciona como un carrito de pedido. Aquí acumula los componentes que desea solicitar antes de confirmar la extracción al almacén.

Agregar artículos

  1. Localice el componente deseado en la cuadrícula de inventario.
  2. Haga clic sobre la tarjeta del componente (si está disponible).
  3. El artículo se agregará automáticamente a la lista de extracción con cantidad 1.
  4. Si el artículo ya estaba en la lista, la cantidad se incrementará en 1.
⚠️
No puede agregar un artículo con stock agotado. El botón de dicho artículo aparecerá deshabilitado (opaco).

Modificar cantidades

Dentro de la lista de extracción, para cada artículo puede:

ControlFunción
Botón −Reduce la cantidad en 1 (mínimo: 1)
Campo numéricoIngrese directamente la cantidad deseada
Botón +Aumenta la cantidad en 1
Botón ❌Elimina el artículo de la lista
ℹ️
La cantidad máxima que puede solicitar de un artículo está limitada al stock disponible en ese momento.

Confirmar pedido

  1. Verifique que todos los artículos y cantidades en la lista sean correctos.
  2. Haga clic en el botón "CONFIRMAR PEDIDO Y EXTRAER".
  3. El sistema enviará las coordenadas al robot automatizado.
  4. Espere a que el robot ejecute la extracción físicamente.
  5. El inventario se actualizará automáticamente.
  6. La lista de extracción se vaciará al completarse el pedido.
✅
Cada pedido queda registrado en el historial de actividad del sistema con la fecha, hora, usuario y artículos solicitados.
⚠️
No confirme el pedido si la lista está vacía. Asegúrese de tener al menos un artículo antes de presionar el botón de confirmación.

6 Sistema de Alerta (Andon)

El Sistema Andon permite a cualquier operador solicitar asistencia técnica o reportar un problema urgente al personal del almacén. Se activa mediante el botón rojo de emergencia (🚨) visible en el panel principal.

🚨
Úselo solo cuando sea necesario. Al enviar una alerta, el sistema bloquea operaciones adicionales hasta que el encargado de almacén atienda y cierre la alerta.

¿Cómo enviar una alerta?

  1. Haga clic en el botón de emergencia 🚨.
  2. Se abrirá un formulario de alerta.
  3. Describa brevemente el problema o la asistencia que requiere.
  4. Haga clic en Enviar Alerta.
  5. El sistema notificará al personal de almacén de forma inmediata.

¿Qué sucede después de enviar la alerta?

  1. La alerta aparece en la terminal del almacén con su nombre, área y descripción.
  2. En su terminal, el sistema mostrará un aviso de "Alerta en espera".
  3. El encargado de almacén acudirá a atender su solicitud.
  4. Una vez atendida, el encargado marcará la alerta como resuelta.
  5. El sistema se desbloqueará y podrá continuar operando normalmente.

Vista del Operador

Ve un aviso de que su alerta fue enviada y debe esperar a ser atendido. Las operaciones quedan en espera.

Vista del Almacén

Recibe un modal de alerta con el nombre del operador, su área y el problema descrito. Debe presionar "Atendido" para cerrar.

7 Panel de Administración

🔐
El Panel de Administración es exclusivo para el Encargado de Almacén. Solo está disponible en la terminal principal del almacén (localhost) y para usuarios con área asignada "Almacén".

Para acceder, haga clic en el botón "Panel Admin" ubicado en la barra superior. El panel contiene tres pestañas:

📦 Inventario
|
📋 Actividad
|
🕐 Cortes de Turno

Pestaña: Inventario

Muestra una tabla con todos los artículos registrados en el sistema, incluyendo su nombre, código BIN, área asignada y stock actual.

Actualizar existencias

  1. Localice el artículo a actualizar en la tabla.
  2. En la columna "Nueva Cantidad", ingrese el valor deseado.
  3. Haga clic en el botón Actualizar de esa fila.
  4. La celda parpadeará en verde para confirmar la actualización exitosa.
ℹ️
Solo puede aumentar el stock desde este panel, no reducirlo. La cantidad mínima permitida es siempre igual al stock actual. Las reducciones ocurren automáticamente al confirmar pedidos de extracción.

Pestaña: Actividad

Muestra un registro cronológico de las últimas 50 acciones realizadas en el sistema, ordenadas de la más reciente a la más antigua.

ColumnaDescripción
Fecha / HoraMomento exacto en que ocurrió la acción
UsuarioNombre o ID del empleado que realizó la acción

Tipos de acciones registradas:

  • Inicio y cierre de sesión
  • Confirmación de pedidos (con detalle de artículos y cantidades)
  • Actualizaciones de stock
  • Alertas Andon enviadas y atendidas
  • Cortes de turno generados
  • Accesos al panel de administración

Los cortes se generan automáticamente en la terminal del almacén (servidor) a las horas indicadas. No es necesario generarlos manualmente. Se muestran los últimos 50 cortes registrados.

10 Preguntas Frecuentes

¿Por qué no puedo ver algunos componentes?

Solo se muestran los componentes asignados a su área. Si necesita acceder a un componente de otra área, solicítelo al encargado de almacén.

¿Qué hago si el robot no responde después de confirmar el pedido?

Si el pedido fue aceptado por el sistema pero el robot no realizó la extracción, use el botón de alerta 🚨 para notificar al encargado de almacén.

¿Puedo cancelar un pedido ya confirmado?

No es posible cancelar un pedido una vez confirmado desde la interfaz. Contacte de inmediato al encargado de almacén si necesita revertirlo.

¿Por qué el botón "Panel Admin" no aparece en mi sesión?

El Panel de Administración está disponible únicamente para usuarios con área "Almacén" y solo cuando se accede desde la terminal del almacén (dirección localhost).

¿Qué significa "Terminal Remota" vs "Servidor Almacén"?

Terminal Remota indica que está accediendo desde una computadora diferente a la del almacén. Servidor Almacén aparece solo en la terminal principal del almacén y habilita funciones adicionales como recepción de alertas y generación de cortes.

¿Qué hago si olvidé mi contraseña?

Contacte al encargado de almacén o al administrador del sistema para que restablezca sus credenciales de acceso.

¿El sistema guarda mi sesión si cierro el navegador?

Sí. La sesión se mantiene activa mientras no presione Cerrar Sesión. Al abrir el navegador nuevamente, su sesión se restaurará automáticamente.

¿Por qué el artículo que solicité bajó de stock más de lo que pedí?

El stock se descuenta en tiempo real para todos los usuarios. Es posible que otro operador haya confirmado un pedido del mismo artículo al mismo tiempo. Si detecta una discrepancia, notifique al encargado de almacén.

11 Glosario

SIGAB
Sistema de Gestión y Almacenaje de Bienes. Nombre del sistema.
BIN
Código alfanumérico que identifica la ubicación física de un artículo dentro del almacén automatizado.
Andon
Sistema de alerta de origen japonés (manufactura esbelta) que permite a los operadores señalar problemas de forma visual o digital para detener y corregir el proceso.
Extracción
Proceso por el cual el robot automatizado recupera físicamente uno o más componentes del almacén tras recibir un pedido confirmado.
Corte de Turno
Resumen automático generado al final de cada turno de trabajo, que contiene el detalle de todos los pedidos procesados durante ese período.
Stock
Cantidad de unidades disponibles de un artículo en el inventario del almacén.
SKR
Placa controladora de motores paso a paso (stepper drivers). Recibe las coordenadas de destino desde el ESP32 y genera los pulsos eléctricos precisos para mover el robot en los ejes X y Z hasta el BIN solicitado.
ESP32
Microcontrolador con conectividad WiFi que actúa como puente entre la interfaz web (SIGAB) y la placa SKR. Recibe las órdenes de extracción vía HTTP POST, las retransmite a la SKR para el movimiento y, una vez posicionado el robot, activa la pinza que recoge físicamente el BIN solicitado.
Pinza
Mecanismo de agarre controlado por el ESP32 que se activa al final del recorrido del robot. Es el componente que toma físicamente el BIN del estante y lo extrae para entregarlo al operador.
Motor paso a paso (Stepper)
Motor de precisión que se desplaza en incrementos fijos (pasos). La SKR controla dos: uno para el eje X (horizontal) y otro para el eje Z (vertical) del robot de almacén.
Strapi
Sistema de gestión de contenidos utilizado como base de datos y API del sistema SIGAB.
JWT
JSON Web Token. Credencial cifrada que autentica al usuario en el sistema.
Servidor (localhost)
Terminal principal del almacén, desde donde se administra el sistema y se escuchan las alertas de los operadores.
